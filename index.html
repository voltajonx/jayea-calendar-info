Calendar help.
On your terms.

JayEA Calendar connects a private executive assistant to its owner’s personal Google Calendar. It can check upcoming events and add or update an event when the owner directly asks.

01 / PURPOSE

A specific request.
A verified result.

The assistant resolves the date, time and duration, checks the primary calendar for overlapping events, and asks before proceeding with a conflict. Saved changes are read back before the assistant reports success.

The integration supports standalone personal events without guests. It is not a booking service, a public calendar, or an autonomous scheduler.

02 / BOUNDARIES

Useful access.
Clear limits.

The assistant’s calendar tool offers reading, creation and editing only. It does not offer deletion, guest invitations, invitation responses, recurring-series edits, or changes to calendar sharing and settings.

Google’s permission for events on owned calendars is broader than these tool limits and includes deletion at the authorization level. The integration does not expose that operation. Requests to review a schedule or suggest a plan do not authorize calendar changes.

03 / PRIVACY

Information here.
Calendar data elsewhere.

This website contains app information only. It has no Google sign-in, calendar connection, forms, analytics scripts, or calendar display. Private calendar information and authorization credentials are not published here.

Calendar information used by the assistant can be processed in private assistant conversations and replies. Read the privacy policy for data flows, storage, third-party services and disconnection details.

Already using JayEA? Use the existing private Discord conversation for calendar requests and support. There is no public signup or connection flow on this site.
